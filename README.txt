NERO BOTZ - PLAY2 RENDER SERVICE

Deploy folder ini sebagai Web Service di Render.
Build Command: npm install
Start Command: npm start
Environment: tidak perlu menambahkan PORT (Render mengaturnya otomatis).

Setelah deploy, salin URL HTTPS service Render, misalnya https://nama-service.onrender.com
Lalu masukkan URL tersebut ke environment bot AMGeekz sebagai PLAY2_REMOTE_URL.

Endpoint pemeriksaan: /health
